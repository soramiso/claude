# 매매 기록에 말로 묻기

API 키 없이, 자동매매가 남긴 CSV 에서 답을 바로 계산하는 규칙 봇이다.
숫자는 파일에서 그대로 더하므로 지어낼 여지가 없고, 모르는 질문은 모른다고 한다.

처음에는 키워드 한 줄로 의도를 갈랐다. 문장이 조금만 달라도 못 알아들어서,
말을 알아듣는 부분(`nlu.py`)을 따로 떼어 내고 다음을 받아 줄 수 있게 넓혔다.

| | 전 | 후 |
|---|---|---|
| 의도 판정 | 먼저 걸리는 키워드 하나 | 키워드마다 점수를 매겨 가장 높은 것 |
| 띄어쓰기·조사 | `"이번 주"`, `"이번주"` 를 따로 적어 둠 | 다듬은 뒤 비교하므로 신경 쓸 필요 없음 |
| 오타 | 못 알아들음 | 자모로 풀어 견줌 (`승율`→`승률`, `보유종묵`→`보유종목`) |
| 기간 | 오늘·어제·이번 주·지난 주·최근 N일·전체 | + 그저께, 이번/지난 달, 올해, 작년, 요일, `9월 3일`, `9월 3일부터 10일까지`, `열흘`, `일주일`, `최근 3개월`, `15일` |
| 종목 | 부르는 쪽에서 미리 뽑아 넘겨야 함 | 기록에서 찾아 이름·코드·줄임말(`삼전`)·초성(`ㅅㅅㅈㅈ`)·앞글자(`삼성`)로 알아봄 |
| 답할 수 있는 것 | 손익·이유·보유·체결·승률 | + 요약, 순위, 자산, 추세, 종목 하나 보기 |
| 이어 묻기 | 없음 | `"그럼 어제는?"`, `"그건 왜 샀어?"` 를 앞 질문에 이어 받음 |
| 한 번에 둘 | 없음 | `"오늘 손익이랑 보유종목"` 을 나눠서 답함 |
| 답 모양 | 표만 | 결론 한 문장 + 표 (`~는/은`, `~이/가` 를 받침에 맞춰 붙임) |

## 쓰기

```python
from pathlib import Path
import rules

답 = rules.answer("이번 주 얼마 벌었어?", Path("기록폴더"))
if not 답:                     # 규칙으로 못 풀면 빈 문자열 — 예전과 같은 약속이다
    답 = claude_api(질문)      # 그때만 API 로 넘기면 된다
```

이어 묻기까지 받으려면 대화 객체를 하나 두면 된다.

```python
대화 = rules.Conversation(Path("기록폴더"))
대화.ask("삼성전자 어때?")
대화.ask("그건 왜 샀어?")       # 앞 종목을 이어받는다
대화.ask("그럼 어제는?")        # 앞 물음을 이어받고 기간만 바꾼다
```

`Conversation.ask()` 는 못 알아들으면 빈 문자열 대신 되묻는 말을 돌려준다.

터미널에서 바로 시험해 볼 수도 있다.

```
python rules.py 기록폴더               # 이어서 물어보는 모드
python rules.py 기록폴더 "오늘 손익"     # 한 번만 묻기
```

## 읽는 파일

| 파일 | 쓰는 곳 |
|---|---|
| `{실제매매,가상매매}_일별손익.csv` | 손익·자산·추세·요약 |
| `{실제매매,가상매매}_보유종목.csv` | 보유·순위·종목 보기 |
| `{실제매매,가상매매}_거래내역.csv` | 체결·이유·종목 보기 |
| `자동매매_일지.csv` | 이유·승률 |

질문에 `모의` 나 `가상` 이 들어가면 `가상매매_*` 파일을 본다. 없는 칸과
어긋난 줄은 건너뛰므로, 파일이 조금 망가져도 답은 나온다.

## 넓히기

새 질문 종류를 하나 더 받으려면 두 군데만 손대면 된다.

1. `nlu.py` 의 `INTENTS` 에 이름과 키워드·가중치를 한 줄 넣는다.
2. `rules.py` 에 `_이름(base, reading)` 함수를 쓰고 `_HANDLER` 에 건다.

가중치는 더 좁은 뜻일수록 높게 준다. 예를 들어 `"제일"`(순위)은 `"수익"`(손익)
보다 높아야 `"제일 많이 번 종목"` 이 순위로 간다. 고친 뒤에는 시험을 돌린다.

```
python -m unittest discover -p "test_*.py" -v
```
