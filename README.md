# 매매 기록에 말로 묻기

API 키 없이, 자동매매가 남긴 CSV 에서 답을 바로 계산하는 규칙 봇이다.
숫자는 파일에서 그대로 더하므로 지어낼 여지가 없고, 모르는 질문은 모른다고 한다.

처음에는 `rules.py` 한 파일에 키워드 몇 줄이 전부였다. 문장이 조금만 달라도
못 알아들어서, 말을 알아듣는 일을 `nlu/` 패키지로 떼어 내고 크게 넓혔다.

## 어떻게 생겼나

| 조각 | 하는 일 |
|---|---|
| `nlu/text.py` | 유니코드·띄어쓰기·자모 분해와 조립, 조사 붙이기, **어미 벗기기**, 오타 견주기, 두벌식 영타 되돌리기, 말투 판별 |
| `nlu/numbers.py` | 한글 수사(`삼천오백만`), 금액(`10만원`·`1.5억`), 퍼센트, `이상/넘게/미만` 같은 **조건** |
| `nlu/timeframe.py` | 기간 표현 전부. 하루·주·달·해·분기·요일·영업일·시각·**견줄 기준** |
| `nlu/lexicon.py` | 어떤 말이 어떤 뜻으로 가는지 적어 둔 **표**. 대개 여기만 고치면 된다 |
| `nlu/entities.py` | 종목·지표·정렬·집계·방향 집어내기 |
| `nlu/intents.py` | 점수를 매겨 뜻을 고르고, 슬롯을 보고 더 좁은 뜻으로 **옮김** |
| `nlu/parse.py` | 위를 모아 `Reading` 한 덩이로. 앞 질문 이어받기도 여기서 |
| `nlu/explain.py` | 왜 그렇게 알아들었는지 설명 |
| `rules.py` | 읽어 낸 뜻에 맞는 답 문장 만들기 (26가지) |

## 무엇이 넓어졌나

| | 처음 | 지금 |
|---|---|---|
| 알아듣는 뜻 | 5가지 | **32가지** (기록으로 답하는 것 26 + 잡담 3 + 기록 밖 3) |
| 의도 판정 | 먼저 걸리는 키워드 하나 | 키워드·어간·오타에 점수를 매기고, 슬롯을 보고 더 좁은 뜻으로 옮김 |
| 말끝 | `"팔았어"` 만 | 어미를 벗겨 `팔았어/파셨나요/매도했지/털었니` 를 한 어간으로 |
| 오타 | 못 알아들음 | 자모로 견줌 (`승율→승률`, `삼송전자→삼성전자`), 영타(`tkatjdwjswk→삼성전자`) |
| 기간 | 6가지 | 하루·주·달·해·**분기·반기·요일·주말·영업일**, `9월 3일부터 10일까지`, `3주 전`, `열흘`, `장 마감 무렵`, `지난주 대비` |
| 종목 | 부르는 쪽이 넘겨야 함 | 기록에서 찾아 이름·코드·줄임말(`삼전`)·초성(`ㅅㅅㅈㅈ`)·앞글자·오타·영타·별명으로 |
| 숫자 | 없음 | `10만원 넘게`, `5% 이상`, `상위 3개`, `두 번째` 를 조건으로 |
| 대화 | 없음 | `"그럼 어제는?"`, `"그건 왜 샀어?"` 이어받기, 여러 턴 기억 |
| 모를 때 | 빈 문자열 | 빈 문자열(약속 그대로) + 되묻기 + 기록 밖 물음은 왜 못 하는지 설명 |

## 쓰기

```python
from pathlib import Path
import rules

답 = rules.answer("이번 주 얼마 벌었어?", Path("기록폴더"))
if not 답:                     # 규칙으로 못 풀면 빈 문자열 — 예전과 같은 약속이다
    답 = claude_api(질문)      # 그때만 API 로 넘기면 된다
```

이어 묻기까지 받으려면 대화 객체를 하나 두면 된다.

```python
대화 = rules.Conversation(Path("기록폴더"))
대화.ask("삼성전자 어때?")
대화.ask("그건 왜 샀어?")       # 앞 종목을 이어받는다
대화.ask("그럼 어제는?")        # 앞 물음을 이어받고 기간만 바꾼다
```

`Conversation.ask()` 는 못 알아들으면 되묻고, `"내일 뭐 살까"` 처럼 기록에
답이 없는 물음에는 왜 못 하는지 말한다. `answer()` 는 그런 경우 빈 문자열이다.

터미널에서 바로 시험해 볼 수도 있다.

```
python rules.py 기록폴더                  # 이어서 물어보는 모드
python rules.py 기록폴더 "오늘 손익"        # 한 번만 묻기
python rules.py 기록폴더 --why "오늘 손익"  # 답 대신 '어떻게 알아들었는지'
python -m nlu "지난주 대비 이번주 어때"      # 같은 것을 기록 없이
```

시간대별·요일별·최대 낙폭·연승연패·보유 기간·수수료·본전·비중·미체결·
일지 검색·횟수·가장 큰 거래·활동량·되풀이된 실수. `"도움말"` 이라고 물으면
예시를 보여 준다.

## 읽는 파일

| 파일 | 쓰는 곳 |
|---|---|
| `{실제매매,가상매매}_일별손익.csv` | 손익·자산·추세·낙폭·평균·견주기 |
| `{실제매매,가상매매}_보유종목.csv` | 보유·순위·비중·본전 |
| `{실제매매,가상매매}_거래내역.csv` | 체결·횟수·활동량·보유기간·수수료·미체결 |
| `자동매매_일지.csv` | 이유·승률·연승연패·일지 검색 |

질문에 `모의` 나 `가상` 이 들어가면 `가상매매_*` 파일을 본다. 없는 칸과
어긋난 줄은 건너뛰므로, 파일이 조금 망가져도 답은 나온다.

## 넓히기

새 질문을 받게 하려면 대개 두 곳만 고치면 된다.

1. `nlu/lexicon.py` 의 `INTENTS` 에 이름과 키워드·가중치를 한 줄 넣는다.
2. `rules.py` 에 `_이름(base, reading)` 함수를 쓰고 `_HANDLER` 에 건다.

가중치는 **그 뜻에만 쓰이는 말일수록 높게** 준다. 여러 뜻에 걸치는 말
(`수익`, `얼마`, `어때`)은 낮게 주어야 더 좁은 뜻이 이긴다. 같은 낱말을
`keys` 와 `stems` 에 겹쳐 넣으면 점수가 두 번 붙으니 피한다.

뜻이 엉뚱하게 잡히면 무엇에 몇 점이 붙었는지부터 본다.

```
python -m nlu "익절 몇 번 했어"
```

고친 뒤에는 표로 점수를 낸다. `eval_set.py` 에 질문과 기대하는 뜻이
169개 적혀 있고, 기준(93%)을 밑돌면 시험이 실패한다.

```
python test_eval.py                              # 틀린 것만 뽑아 본다
python -m unittest discover -p "test_*.py"       # 전부 (153개)
```

## 한계

말을 정말로 이해하는 것은 아니다. 규칙과 사전일 뿐이다. `"내일 뭐 살까?"`
같은 앞일, 시세 전망, 전략 상담은 기록에 답이 없으므로 빈 문자열을 돌려준다.
그런 질문이야말로 API 로 넘겨야 할 것들이다.

수수료는 기록에 칸이 없으면 요율로 어림잡고, 그렇다고 답에 적어 둔다.
승률·연승연패는 일지의 `익절`·`손절` 판단을 세어 계산한다.
